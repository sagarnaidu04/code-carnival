# Code Carnival - Software Requirements Specification (SRS)

## 1. Project Overview

Code Carnival is an online coding platform where users can practice programming problems, participate in coding contests, and track their progress.

---

## 2. Objectives

- Provide a platform for coding practice
- Conduct programming contests
- Track user performance
- Help students prepare for coding interviews

---

## 3. User Roles

### User
- Register/Login
- Solve Problems
- Submit Solutions
- Participate in Contests
- View Dashboard

### Admin
- Manage Users
- Manage Problems
- Create Contests
- View Reports

---

## 4. Functional Requirements

### Authentication
- User Registration
- User Login
- Password Reset
- JWT Authentication

### Problems
- View Problems
- Search Problems
- Filter Problems
- View Problem Details

### Submissions
- Submit Code
- View Submission History
- Check Verdict

### Contests
- View Contests
- Join Contest
- Leaderboard

---

## 5. Non-Functional Requirements

- Secure Authentication
- Fast Response Time
- Responsive UI
- Scalable Architecture
- RESTful APIs
